# Flower scene reference

The SVG illustration layers in this directory are from the publicly accessible footer of https://doisena.jp/, downloaded on 2026-09-17 for the requested website reproduction.

- Illustration layers: `https://doisena.jp/common/img/footer/type-05/`
- Original layer composition: `https://doisena.jp/common/inc/doisena-anim_05/index.html`
- Reference motion: `https://doisena.jp/common/js/IllustAnim_05.js`
- Reference layout: `https://doisena.jp/common/css/common.css`

The local React component reproduces the individual branch sways, phase offsets, flower face movement and fifteen-second tile drift without executing any scripts from the reference website. The illustration remains the reference artist's artwork.
